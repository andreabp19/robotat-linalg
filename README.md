
# Robotat Linalg Github Pages (gh-pages) branch

## What is this branch for?

All website-related files are in this branch of the Robotat Linalg repository, and has a separate commit history from the `main` branch where the code library files are located.

The purpose of this is to prevent cluttering the `main` branch with files unrelated to the libraries and immediate documentation (doxygen).

## gh-pages branch structure

```
/
├── assets       ← .css, .js, and image files for the website.
├── index.html   ← Landing page
└── README.md    ← Read me file
```
