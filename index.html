About this project

A lightweight embedded numerical library stack, for control and robotics.

Robotat Linalg bridges the gap between developing efficient numerical algorithms and their effective deployment on embedded agents. For this purpose, it provides essential linear algebra, convex optimization, control and robotics algorithms, targeted at single-precision architecture devices.

Features

Library-independent

Robotat Linalg is written entirely in C using the C Standard Library. No external dependencies needed.

Memory-efficient

Matrix definition through static memory allocation (no malloc) for efficient memory management.

Single-Precision Arithmetic

Robust numerical infrastructure for accurate linear algebra and optimization algorithms in single-precision devices.

Multiple platforms

Targets single-precision devices, including Arduino, ESP32 and STM32 boards, and others.

Fast

Execution time of routines between micro- and milliseconds, depending on algorithm complexity and device capacity.

Free to use

Robotat Linalg is free and open-source, using the MIT license. You can use it for your projects, let us know how it goes!
